# FAP Contabilidade

Site institucional da FAP Contabilidade, escritório de contabilidade em Taboão da Serra (SP), especializado em MEI, ME e EPP.

## Estrutura

```
.
├── index.html          # Estrutura e conteúdo da página
├── css/
│   └── style.css       # Estilos (cores, tipografia, layout, modo escuro, animações)
├── js/
│   └── main.js         # Interações (animações, carrossel, menu, formulário → WhatsApp)
└── assets/
    └── img/
        └── logo.png    # Logo da FAP
```

## Recursos

- Layout responsivo (celular, tablet e desktop)
- Modo claro e escuro automáticos, conforme o sistema do visitante
- Formulário que abre a conversa pronta no WhatsApp
- Animações que respeitam a preferência de movimento reduzido
- Dados estruturados (Schema.org) para aparecer melhor no Google

## Como rodar

Não precisa de instalação. Abra o `index.html` no navegador.

## Como publicar

- **GitHub Pages:** em *Settings → Pages*, escolha a branch `main` e a pasta `/ (root)`.
- **Netlify:** arraste a pasta do projeto em [app.netlify.com/drop](https://app.netlify.com/drop).
